# KALIEVA TRAVEL — лендинг туристического агентства

Учебный проект: одностраничный сайт туристического агентства по Казахстану.
Автор — Калиева Аружан.

## Что на странице

- первый экран с ключевым предложением и цифрами агентства;
- семь маршрутов: Чарын, Кольсай, Каинды, Мангистау, Туркестан, Алтын-Эмель, Бурабай;
- расписание заездов с фильтром по месяцам — рендерится из массива в `script.js`;
- блок об агентстве и отзывы;
- форма заявки с маской телефона, валидацией и подстановкой выбранного тура;
- адаптив от 360 px до широких экранов.

## Стек

Чистые HTML, CSS и JavaScript без фреймворков и сборщиков.
Шрифты — Fraunces и Inter с Google Fonts, при отсутствии сети подставляются системные.

## Как запустить

Открыть `index.html` в браузере. Либо поднять локальный сервер:

```
python3 -m http.server 8000
```

и зайти на http://localhost:8000

## Структура

```
landing-kalieva/
  index.html      разметка
  styles.css      стили
  script.js       расписание, фильтр, маска телефона, валидация формы
  assets/         фотографии маршрутов
  CREDITS.md      авторы и лицензии фотографий
```

## Форма заявки

Бэкенда нет: по сабмиту данные валидируются и выводятся в консоль браузера.
Телефон хранится в состоянии чистыми цифрами (`77071234567`), форматирование
`+7 (707) 123-45-67` — производная от них, поэтому удаление и вставка из буфера
работают корректно. В payload уходят цифры и E.164.
